# Pipeline stages

Use these five stages, in order:

1. New: came in, nobody has contacted them yet.
2. Contacted: we have had a first conversation or sent a message.
3. Meeting: a meeting or call has happened.
4. Proposal: a written proposal or price list has been sent.
5. Invoice sent: an invoice has been sent and payment is pending.

Two end stages:

- Paid: the full amount is received.
- Lost: they said no or went silent for 30+ days.

Each company needs a next follow-up date. An overdue follow-up is one whose date is before today (1 Nov 2026).
Deal value is in BDT. Leave it empty or 0 if no value has been agreed yet.
