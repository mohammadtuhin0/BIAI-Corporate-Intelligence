
# BIAI Corporate Intelligence

An AI-powered corporate leads pipeline developed
for the BIAI AI Internship Round 2 challenge.

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- SQLite
- Google Gemini API

## Core Features

- Corporate lead management
- Sales pipeline tracking
- Data quality validation
- Overdue follow-up detection
- AI-powered email generation
- Natural-language business queries

## Dataset

Uses the 25 fictional corporate leads provided
in the official BIAI Round 2 challenge pack.
